# Queries for the legacy API usage

The queries that measure the use of `api.surveyjs.io` (requests per endpoint, per hour and per day, and the client
types) run against the old service's monitoring and logs. They are kept in the legacy documentation, in the private
location (plan-hosted.md, rule 6), together with their results.

Only the shares and plain-word findings come back to this repository:
[Legacy API usage](../architecture/legacy-api-usage.md).
