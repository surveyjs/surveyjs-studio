# SurveyJS Studio Docker Image Terms

These terms apply to the official SurveyJS Studio self-hosted Docker image
published by Devsoft Baltic OÜ.

## Free self-hosted use

Devsoft Baltic OÜ grants you permission to run the official image on
infrastructure you control, including in production, and to use the copies of
Survey Creator and SurveyJS Dashboard included in that image, free of charge,
subject to the following conditions.

- Run the official image as supplied. You may configure your deployment using
  the documented settings, including your instance name, logo, colors, domain,
  and URLs.
- Keep the **Powered by SurveyJS** attribution visible in the locations where
  the image displays it.

The image includes a special license key for use under these terms. The key removes
the commercial components' license warning. The **Powered by SurveyJS**
attribution remains visible.

## Custom builds and white-label deployments

This grant covers the commercial components as included in the official image. 
If you edit the Studio source code and build your own image, that's a custom build. 
Production use of Survey Creator or SurveyJS Dashboard in that build requires an 
applicable [SurveyJS developer license](https://surveyjs.io/licensing).
To disable the attribution in the official image, supply a SurveyJS license
key that permits white-label use.
