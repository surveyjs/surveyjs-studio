# Security policy

## Supported versions

We fix security problems in the latest release. Older releases get no fixes. Update before you report, if you can.

## Report a vulnerability

Report it privately. Do not open a public issue, a pull request or a discussion.

1. Use GitHub's private vulnerability reporting:
   [Report a vulnerability](https://github.com/surveyjs/surveyjs-studio/security/advisories/new).
2. If you cannot use GitHub, write to `support@surveyjs.io` with "Security" in the subject.

## What to include

- The version, the image tag or the commit.
- The mode you run: the user directory, the storage provider and the sign-in methods.
- The steps to reproduce the problem.
- What you expected and what happened.
- The impact, as you see it.
- Any proof of concept. Please do not include real credentials or other people's data.

We will confirm the report and keep you informed until it is fixed. Please give us time to ship a fix before you
disclose the problem.
